# GRID_Python_U1_U3_SetA

This folder contains six standalone Python scripts demonstrating core Python concepts. Run a script with Python 3 from this folder, for example `python sectionA.py`. `sectionB.py` prompts for an item name, price, and quantity.

## Files

| File | Topics covered |
| --- | --- |
| `sectionA.py` | Print formatting with `sep` and `end`, multiple assignment, escape characters, quote escaping, and swapping values. |
| `sectionB.py` | Interactive input, converting strings to numbers, calculating a total with an f-string, handling `ValueError` and `TypeError`, and conversion/division behavior. |
| `sectionC.py` | Built-in type names, dynamic typing, floating-point comparison, booleans, truthiness, and `isinstance`. |
| `sectionD.py` | Floor division, modulo, operator precedence, division result types, and a shopping bill with tax. |
| `sectionE.py` | Chained comparisons, logical operators and short-circuiting, and compound assignment operators. |
| `sectionF.py` | String indexing and slicing, immutability, exception handling, trimming and splitting, case conversion, searching, replacement, and formatting styles. |

## Notes

- Each script is independent and prints demonstrations to the terminal.
- The scripts use only Python's standard library.
- `sectionB.py` expects a numeric price and a whole-number quantity.
- Several scripts intentionally trigger errors inside `try`/`except` blocks to demonstrate handling them.

A PDF file guide with the same six-file inventory is provided as `files_guide.pdf`.
